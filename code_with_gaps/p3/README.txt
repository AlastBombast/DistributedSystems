`client-with-server.c` in this folder, along with the `Makefile` 
that compiles everything.

In `server.c`, mark the lines you have added by preceding them 
with a comment that says "ADDED" followed by your full name.

in the instructions to allow reusing the socket port. 
Mark the added lines in the same way.

In the `client-with-server.c` code, since you are not starting from 
a base code, you cannot mark modified lines; however, clearly indicate 
the parts dealing with the new PONG command with a comment 
saying "ADDED" followed by your full name.
